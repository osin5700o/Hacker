# `Ethical Hacking~#`

> `Module 01: Introduction to Ethical Hacking – Covers information security basics, ethical hacking concepts, security controls, and cyber laws.`

> `Module 02: Footprinting and Reconnaissance – Teaches intelligence gathering and OSINT techniques to map target attack surfaces.`

> `Module 03: Scanning Networks – Explores network scanning methodologies, host discovery, and port scanning tools.`

> `Module 04: Enumeration – Focuses on active information extraction like SMB, SNMP, and NetBIOS enumeration.`

> `Module 05: Vulnerability Analysis – Identifies security weaknesses and flaws in target systems before exploitation.`

> `Module 06: System Hacking – Covers password cracking, escalating privileges, executing applications, and hiding files.`

> `Module 07: Malware Threats – Analyzes Trojans, viruses, ransomware, and AI-generated malware mechanics.`

> `Module 08: Sniffing – Explains network traffic analysis, MAC flooding, and ARP poisoning detection.`

> `Module 09: Social Engineering – Examines human-based attacks including phishing, spear-phishing, and deepfake manipulation.`

> `Module 10: Denial-of-Service (DoS/DDoS) – Looks at availability disruption techniques and mitigation tactics.`

> `Module 11: Session Hijacking – Teaches how attackers take over valid user sessions and preventive controls.`

> `Module 12: Evading IDS, Firewalls, and Honeypots – Demonstrates bypass methods for perimeter security controls.`

> `Module 13: Hacking Web Servers – Focuses on web server vulnerabilities, attack vectors, and patching strategies.`

> `Module 14: Hacking Web Applications – Explores web app architectures, OWASP Top 10 vulnerabilities, and testing.`

> `Module 15: SQL Injection – Covers database attack mechanisms, injection testing, and secure coding fixes.`

> `Module 16: Hacking Wireless Networks – Teaches Wi-Fi encryption weaknesses, rogue access points, and wireless sniffing.`

> `Module 17: Hacking Mobile Platforms – Analyzes Android and iOS security models, application flaws, and mobile device management.`

> `Module 18: IoT and OT Hacking – Explores connected smart device risks, industrial control systems, and hardware security.`

> `Module 19: Cloud Computing – Covers cloud service models (IaaS, PaaS, SaaS), shared responsibility, and misconfigurations.`

> `Module 20: Cryptography – Explores encryption algorithms, public-key infrastructure, and post-quantum cryptography.`


> These are the topics we have to know in basics , And the syllabus is under CEHv13 certificate. After this you can go with any fields of Hacking.
